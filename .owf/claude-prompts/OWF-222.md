# OWF-222: monthly_income accesible desde Lite

## Contexto
`monthly_income` (Ingreso Mensual Esperado) solo es configurable desde el tab Finanzas de Config en Pro. Los usuarios Lite no tienen forma de setearlo desde ningún lado. Esto alimenta las sugerencias de distribución de cántaros.

## Objetivo
Agregar acceso a `monthly_income` desde Lite. Opciones:
- **Opción A**: Agregar campo en `/user/financial-profile` (ya tienen ingresos, metas, etc.)
- **Opción B**: Agregar campo en Config Lite (bloque "Aplicación" o sección nueva)

Recomendada: **Opción A** — financial-profile ya maneja `income_range`, agregar `monthly_income` como campo numérico real.

## Pasos
1. Verificar el endpoint: `PUT /user/financial-profile` ya acepta campos del perfil
2. Si `monthly_income` no está en financial_profile, agregarlo al backend (migración si hace falta)
3. Agregar campo en `src/pages/user/financial-profile/index.vue`
4. Verificar que Lite puede acceder a financial-profile (ya está en nav desde OWF-216)
5. Build: `cd OWFinanceFrontend2025 && npx quasar build -m spa`
6. Deploy backend (si hubo cambios) + frontend
7. Actualizar TASKS.md (OWF-222 → [x]) y STATE.md

## Notas
- Backend: `OWFINANCEBackend2025/`
- El campo existe en tabla `users` como `monthly_income` (nullable)
- Endpoint actual: `GET/PUT /api/v1/user/financial-profile`
