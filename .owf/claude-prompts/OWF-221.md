# OWF-221: Consolidar tasas de cambio triplicadas

## Contexto
Hay 3 componentes que leen/escriben la tabla `user_currencies` independientemente:
1. **"Mis Tasas de Cambio"** CRUD en tab Finanzas de Config Pro (`src/pages/user/config/index.vue`)
2. **ExchangeRatesWidget.vue** embebido en ProHomeView
3. **ExchangeRatesTable.vue** en bloque unificado de Config (creado OWF-207)

## Objetivo
ExchangeRatesTable.vue debe ser el componente canónico. Los otros 2 deben:
- Si hacen lo mismo → eliminar y reemplazar por ExchangeRatesTable
- Si tienen funcionalidad única → extraerla a ExchangeRatesTable y eliminar

## Pasos
1. Leer los 3 componentes
2. Crear tabla comparativa: features de cada uno
3. Migrar cualquier feature faltante a ExchangeRatesTable
4. Reemplazar usos de los otros 2 por ExchangeRatesTable
5. Eliminar código muerto
6. Build: `cd OWFinanceFrontend2025 && npx quasar build -m spa`
7. Actualizar TASKS.md (OWF-221 → [x]) y STATE.md
