## Filosofía

Un sistema sostenible no requiere 8 horas diarias — requiere **1 hora diaria ejecutada con consistencia**.
El problema nunca fue falta de tiempo. Fue falta de sistema.

---

## Sistema Semanal (1H Diaria)

| Día | Foco | Actividad |
|-----|------|-----------|
| Lunes | Marca personal | Post LinkedIn / contenido oteroweb.com |
| Martes | OWFinances producto | Dev, diseño, documentación |
| Miércoles | Contenido video | Guión, grabación o edición |
| Jueves | Consultoría / B2B | Propuestas, outreach, networking |
| Viernes | Revisión + planificación | Review semana, plan siguiente |
| Sábado | SOV-OW / sistema | Mejoras al ecosistema personal |
| Domingo | Descanso o buffer | Solo si hay urgencia real |
